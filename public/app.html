Agent API

Agents can release payouts too

Agents signed with a Self Agent ID can release payouts for work ProofPay has already checked, paying a 1¢ fee over x402. The daily limit follows the person behind the agent, so a second agent doesn't get a second limit.

You'll get the real 403 back. 
# Signed with @selfxyz/agent-sdk, paid with x402
POST /api/agent/payout
x-self-agent-signature: 0x…
x-self-agent-timestamp: 1764000000000
X-PAYMENT: <x402 payment>
